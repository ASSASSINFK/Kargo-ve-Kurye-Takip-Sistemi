# Global Express Kargo ve Takip Sistemi

📌 **Projenin Amacı:** Uluslararası lojistik süreçlerini dijitalleştiren web tabanlı bir operasyon yönetim sistemidir. Kargoların ülkeler arası aktarma merkezlerinden (Hub) geçişi gerçek dünya verileri kullanılarak takip edilir.

## 🗄️ Veri Tabanı Mimarisi (8 Tablo)
Sistem, gereksiz veri tekrarını önleyecek şekilde (normalize) tasarlanmıştır:
1. `Laender`: Gerçek ülke ISO kodları (Örn: DE, PL).
2. `Hubs`: Gerçek operasyon merkezleri (Örn: Leipzig Hub).
3. `Kunden`: Gönderici ve alıcı profilleri.
4. `Sendungen`: Ana kargo operasyonları tablosu.
5. `Sendungsarten`: Document, Parcel gibi kargo türleri sözlüğü.
6. `Statuscodes`: Gümrük ve transit geçiş durum sözlüğü.
7. `Tracking_Logs`: Kargoların zaman damgalı hareket geçmişi.
8. `Kuriere`: Sahada dağıtım yapan personeller.
